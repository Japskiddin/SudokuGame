# Проверка на устройствах

- Проверяй изменения, затрагивающие Android, на физическом Android-устройстве. Устанавливай свежую сборку с сохранением данных приложения и проходи затронутый сценарий. Запускай инструментальные тесты на физическом устройстве.
- Проверяй изменения Desktop запуском собранного приложения на физическом компьютере с целевой ОС.
- Используй только физические устройства для приёмочной проверки. Если нужное устройство недоступно, укажи, какая проверка осталась невыполненной.
